Códigos prontos

Cada funcionalidade com o HTML, o CSS e o JavaScript de que ela precisa, e nada além disso. Funcionam num projeto em branco.

Como usar

  1. Comece pela estrutura. O primeiro código cria os três arquivos do projeto já conectados. Todo o resto é colado dentro deles.
  2. Escolha uma funcionalidade e abra o painel dela. Veja o exemplo funcionando pelo link "Ver funcionando".
  3. Cole cada aba no arquivo certo: HTML no index.html, CSS no estilo.css, JS no script.js. O painel diz onde colar.
  4. Troque o conteúdo: textos, fotos (src e alt) e cores. Salve e confira no navegador antes de colar o próximo.
Dá para usar vários juntos. Os códigos foram feitos para não brigar entre si: nenhum nome de variável se repete. A classe .botao aparece em vários CSS com as mesmas regras; se já colou uma vez, não precisa repetir.
