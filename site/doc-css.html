1. O que é CSS e como ligar ao HTML

CSS quer dizer Cascading Style Sheets: folhas de estilo em cascata. O HTML diz o que cada coisa é; o CSS diz como ela aparece: cor, tamanho, espaço, posição, animação. "Em cascata" porque várias regras podem valer para o mesmo elemento, e existe uma ordem para decidir qual vence (capítulo 4).

Existem três jeitos de colocar CSS numa página. Use o primeiro:

JeitoComoQuando
Arquivo externo (recomendado)<link rel="stylesheet" href="css/estilo.css"> no headSempre. Um arquivo serve a todas as páginas: mudou uma vez, muda o site todo.
Tag style<style> p { color: red; } </style> no headTestes rápidos, ou CSS que só vale para uma página.
Atributo style<p style="color: red">Quase nunca. Mistura aparência com conteúdo e é difícil de mudar.

Erro comum: escrever <style> dentro do arquivo .css

Dentro do estilo.css só existe CSS. As tags <style> e </style> são HTML e, no .css, fazem a primeira regra ser ignorada.

2. Anatomia de uma regra

.card {
  background-color: white;
  padding: 1rem;
}
  • Seletor: QUEM vai mudar. Aqui, todo elemento com class="card".
  • Chaves: o bloco de declarações começa em { e termina em }.
  • Propriedade: O QUE muda (a cor de fundo, o espaço interno).
  • Valor: COMO fica. Depois dos dois-pontos; termina com ponto e vírgula.

Uma propriedade + valor é uma declaração. O conjunto seletor + bloco é uma regra. O arquivo CSS é só uma lista de regras.

Erro comum: esquecer o ponto e vírgula ou os dois-pontos

Sem ; a declaração seguinte "gruda" na anterior e as duas são ignoradas. O navegador não avisa: a regra só não funciona. No F12, a declaração aparece riscada ou com um ícone de aviso.

SeletorEscolheExemplo

Na prática

Prefira classes para estilizar. Tag sozinha é boa para o estilo básico (todo p, todo a). id é forte demais no CSS (difícil de sobrescrever): deixe os ids para os links #âncora e para o JavaScript.

Experimente: teste seletores num HTML de verdade

Escreva um seletor e veja quais elementos ele escolhe. Use os botões para exemplos prontos.

Confira: Qual seletor escolhe só os links do menu, e não os links do texto: a, .menu a ou .menu?

Ver a resposta

.menu a: os a que estão dentro do elemento com class="menu". a pega todos os links; .menu pega a caixa do menu, não os links.

4. Cascata, especificidade e herança

Quando duas regras mudam a mesma propriedade do mesmo elemento, qual vence? O navegador decide nesta ordem:

  1. !important vence tudo (evite: é um atalho que depois ninguém consegue sobrescrever).
  2. Atributo style escrito na própria tag vence qualquer seletor do arquivo CSS (por isso o CSS fica melhor no arquivo).
  3. Especificidade: o seletor mais específico vence. Conte (ids, classes, tags): id vale mais que qualquer quantidade de classes, e classe vale mais que qualquer quantidade de tags.
  4. Ordem: empatou? Vence a que está mais para baixo no arquivo.

Experimente: calcule a especificidade

Escreva dois seletores e veja qual vence.

Herança

Algumas propriedades passam do pai para os filhos sozinhas: as de texto (color, font-family, font-size, line-height, text-align). Por isso basta definir a fonte no body. As de caixa (margin, padding, border, background, width) não passam.

Erro comum: "mudei o CSS e não aconteceu nada"

Aperte F12, clique no elemento (aba Elements) e olhe o painel Styles: as declarações riscadas perderam para outra regra, e o painel mostra qual venceu e em que linha ela está.

5. O modelo de caixa (box model)

Para o CSS, todo elemento é uma caixa com quatro camadas, de dentro para fora: conteúdo, padding (espaço interno), border (borda) e margin (espaço externo, que afasta os vizinhos).

Experimente: mexa nas camadas da caixa

Laranja = margin, amarelo escuro = border, verde = padding, azul = conteúdo. Troque o box-sizing e veja a conta mudar.

Quantos valoresSignificaExemplo
1os 4 lados iguaispadding: 1rem;
2vertical | horizontalmargin: 0 auto; (centraliza)
3topo | laterais | baixomargin: 0 auto 2rem;
4topo | direita | baixo | esquerda (sentido do relógio)padding: 4px 8px 4px 16px;

Curiosidade que confunde

Duas margens verticais que se encontram não somam: a maior vence (margin collapse). Entre um h2 com margin-bottom de 20px e um p com margin-top de 10px, a distância fica em 20px, não em 30px. Isso só acontece entre blocos comuns; entre itens de flex e de grid, as margens somam.

6. Unidades e cores

%o elemento pailarguras flexíveis
vw / vha largura / altura da janelaseções de tela cheia, títulos que crescem

Por que rem para fontes? Quem enxerga pouco aumenta a letra nas configurações do navegador. Com rem, o site inteiro acompanha. Com px, não.

Cores podem ser escritas com nome (white), hexadecimal (#12324a: vermelho 12, verde 32, azul 4a) ou rgb/rgba (o quarto número é a opacidade: 1 é totalmente visível, 0 é invisível). Para escolher, use um seletor de cores e confira o contraste entre texto e fundo (procure "contrast checker"): o mínimo recomendado é 4,5 para 1.

7. display: como a caixa se comporta

ValorComportamento
blockocupa a linha inteira; aceita width, height, margin (p, div, section, h1...)
inlinefica no meio do texto; ignora width e height (a, span, strong)
inline-blockfica na linha, mas aceita width, height e padding
flexos filhos viram itens flexíveis, alinhados numa direção (capítulo 8)
gridos filhos são arrumados em linhas e colunas (capítulo 9)
nonesome da página, como se não existisse

Esconder: display: none tira o elemento e o espaço dele. visibility: hidden e opacity: 0 escondem, mas mantêm o espaço. O atributo hidden do HTML equivale a display: none, com um cuidado: se o CSS der outro display ao elemento (por exemplo, .caixa { display: flex; }), o hidden para de funcionar. A solução é acrescentar [hidden] { display: none !important; } no CSS.

8. Flexbox: alinhar numa direção

Flexbox arruma os filhos de uma caixa em uma direção (linha ou coluna) e resolve os alinhamentos que antes eram difíceis: centralizar, espaçar igualmente, mandar um item para o canto. É o que se usa em menus, cabeçalhos, barras de botões e cards lado a lado.

Experimente: mude as propriedades do flex

As propriedades vão no PAI (a caixa). Os números são os filhos.

Para não confundir

justify-content alinha na direção principal (na horizontal, se flex-direction for row). align-items alinha na direção cruzada (na vertical). Com flex-direction: column, os dois trocam de papel.

9. Grid: linhas e colunas

Grid arruma os filhos em duas direções ao mesmo tempo: linhas e colunas. Use para grades de cards, galerias e o layout da página inteira.

Experimente: mude as colunas

Escolha a opção auto-fit e diminua a largura da caixa com o último controle: as colunas se reorganizam sozinhas, sem @media.

Flex ou grid? Flex quando o conteúdo manda (uma fila de itens de tamanhos diferentes). Grid quando o layout manda (colunas definidas). Os dois convivem: um card de um grid pode ter flex dentro.

Experimente: compare os valores de position

ValorUso típico

relativeno elemento que serve de referência para algo absolute (normalmente o pai)
absoluteetiqueta sobre uma foto, botão X no canto de um card

Com position diferente de static, use top, right, bottom, left para posicionar e z-index para decidir quem fica na frente.

11. Site responsivo: celular primeiro

Responsivo é o site que se adapta a qualquer tela. A maior parte dos seus visitantes vai estar no celular. Receita:

  1. Tenha o meta viewport no HTML (sem ele, nada funciona no celular).
  2. Use larguras flexíveis (%, max-width, fr, auto-fit) em vez de width fixo em px.
  3. Imagens com max-width: 100% e height: auto.
  4. Escreva o CSS pensando no celular primeiro. Depois acrescente @media (min-width: ...) para telas maiores.
  5. Teste no F12: o ícone de celular (Ctrl + Shift + M) simula várias telas.

12. Variáveis CSS e tema escuro

Variáveis guardam valores que se repetem. Você cria no :root com um nome começando por --, e usa com var(). Para um tema escuro, basta trocar o valor das variáveis.

É exatamente assim que funciona o botão de tema escuro deste site. O código completo está em Códigos, no grupo Interatividade, em "Tema escuro".

13. Transições e animações

transition anima a mudança de um estado para outro (normal → hover). @keyframes + animation criam animações que rodam sozinhas.

Erro comum: colocar o transition no :hover

O transition vai no estado NORMAL. Se estiver só no :hover, a animação acontece ao entrar, mas ao sair o elemento volta de uma vez.

14. Descobrir o problema com o F12

  1. Clique com o botão direito no elemento → Inspecionar.
  2. No painel Styles aparecem todas as regras que valem para ele, a mais forte em cima. Riscado = perdeu. Com triângulo amarelo = propriedade ou valor escrito errado.
  3. Clique num valor e mude com as setas do teclado: você vê o resultado na hora (e depois copia para o arquivo, porque o F12 não salva).
  4. Na aba Computed, o desenho do modelo de caixa mostra margin, border e padding de verdade.
SintomaCausa provável
Nenhum estilo funcionaCaminho do link errado, ou <style> dentro do .css
Uma regra não funcionaSeletor escrito diferente do HTML (classe com letra trocada), ; faltando, ou perdeu na especificidade
Imagem de fundo não apareceO caminho do url() parte da pasta do CSS: use ../img/foto.jpg
Página com rolagem para o lado no celularAlgum elemento com width fixo maior que a tela
z-index não funcionaO elemento está com position: static (itens de flex e grid são exceção: aceitam z-index assim mesmo)
