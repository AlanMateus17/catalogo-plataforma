Trilha em 10 passos

Do computador vazio ao seu site no ar

Você vai instalar as ferramentas, criar o projeto pelo terminal, guardar tudo no GitHub desde o começo, montar o site com HTML, CSS e JavaScript e publicar no GitHub Pages. Cada passo diz o que digitar, o que deve aparecer na tela e o que fazer quando der errado.

Começar pelo Passo 1 Ver os 10 passos

O que você vai ter no fim

  • Um site seu, no endereço https://seu-usuario.github.io/nome-do-projeto/, que abre em qualquer celular.
  • O código do site num repositório do GitHub, com o histórico de cada mudança, guardado desde o Passo 4.
  • A habilidade de atualizar o site com cinco comandos, de qualquer computador.

Como cada passo funciona

Os comandos aparecem numa caixa escura com o botão Copiar, e logo abaixo vem o que deve aparecer na tela. Compare sempre: se a resposta for diferente, pare e procure o Erro comum daquele trecho.

Confira: uma pergunta rápida. Responda de cabeça antes de abrir a resposta.

Erro comum: o erro que quase todo mundo comete naquele ponto, com a solução.

Você tenta

Um exercício para fazer sozinho, sem resposta pronta.

Pronto quando: a lista do que precisa estar funcionando antes do próximo passo. As marcações ficam salvas só neste navegador, neste computador: em outro computador do laboratório, elas não aparecem.

Os 10 passos

Nenhum passo completo ainda.

  1. 1

    Preparar o computador

    Criar a conta no GitHub, instalar VS Code, Git e GitHub CLI e entrar na sua conta pelo terminal.

    Tempo: 1 a 2 aulas

    0 de 5

  2. 2

    Terminal sem medo

    Ler o prompt, andar entre pastas e criar arquivos com pwd, ls, cd, mkdir e touch.

    Tempo: 1 aula

    0 de 4

  3. 3

    Criar o projeto pelo terminal

    Criar a pasta e os três arquivos, colar a estrutura e ver o site no Live Server.

    Tempo: 1 aula

    0 de 5

  4. 4

    Guardar o projeto no GitHub

    Criar o repositório com git init e commit e enviar com gh repo create. Daqui em diante, o seu trabalho nunca fica só num computador.

    Tempo: 1 aula

    0 de 4

  5. 5

    Montar o conteúdo com HTML

    Planejar a página e montar as seções com os códigos prontos, trocando o conteúdo pelo seu.

    Tempo: 2 aulas

    0 de 5

  6. 6

    Dar a cara do site com CSS

    Suas cores e sua fonte, regras suas e o ajuste para o celular com @media.

    Tempo: 2 aulas

    0 de 5

  7. 7

    Dar vida com JavaScript

    Colocar 2 ou 3 interações e aprender a ler os erros do Console.

    Tempo: 1 a 2 aulas

    0 de 5

  8. 8

    Verificar se está tudo funcionando

    Usar as ferramentas do navegador (F12), o Verificador do projeto, o validador e o Lighthouse.

    Tempo: 1 aula

    0 de 5

  9. 9

    Publicar no GitHub Pages pelo terminal

    Ativar o GitHub Pages com um comando, abrir o seu site na internet e caprichar no link compartilhado.

    Tempo: 1 aula

    0 de 5

  10. 10

    Atualizar o site publicado

    O ciclo de todo dia (pull, status, add, commit, push), voltar a uma versão antiga e continuar em outro computador.

    Tempo: 1 aula

    0 de 4

Quando o terminal mostra um erro

Procure a mensagem na primeira coluna. Com Ctrl + F no navegador, dá para buscar um pedaço dela.

MensagemO que quer dizerO que fazer
bash: comando: command not foundO programa não está instalado, ou o terminal foi aberto antes da instalação.Feche e abra o terminal. Se continuar, reinstale. Ver o passo
No such file or directoryA pasta ou o arquivo não existe onde você está.Rode pwd e ls para ver onde está e o que existe ali. Ver o passo
fatal: not a git repositoryVocê rodou um comando do Git fora da pasta do projeto.Vá para a pasta do projeto (cd ~/projetos/nome-do-projeto). Ver o passo
(main) na sua pasta pessoalAlguém rodou git init fora do projeto.Apague o .git dessa pasta, com cuidado. Ver o passo
Author identity unknownO Git não sabe o seu nome e e-mail.Rode os comandos git config do Passo 1.6 (ou do 4.3, no laboratório). Ver o passo
nothing to commit, working tree cleanNada mudou desde o último commit.Salve os arquivos e confira se está na pasta certa. Ver o passo
src refspec main does not match anyNão existe commit para enviar.Faça o git commit antes do push. Ver o passo
Name already exists on this accountVocê já tem um repositório com esse nome.Use outro nome no gh repo create. Ver o passo
remote origin already existsO projeto já tem um endereço do GitHub.Veja com git remote -v; troque com git remote set-url origin. Ver o passo
To get started with GitHub CLI, please run: gh auth loginO terminal não está logado na sua conta.Rode gh auth login. Ver o passo
[rejected] ... (fetch first) / Updates were rejectedO GitHub tem mudanças que o seu computador não tem.Rode git pull e depois git push. Ver o passo
Need to specify how to reconcile divergent branchesFalta dizer ao Git como juntar as mudanças.Rode git config --global pull.rebase false e o git pull de novo. Ver o passo
CONFLICT (content): Merge conflictA mesma linha mudou em dois lugares.Escolha a versão no VS Code, salve, faça add, commit e push. Ver o passo
HTTP 409 ao ativar o PagesO Pages já está ativo.Só confira o endereço com o comando do 9.2. Ver o passo

The term 'MSYS_NO_PATHCONV=1' is not recognizedO terminal é o PowerShell, não o Git Bash.Troque o terminal para Git Bash. Ver o passo
404 There isn't a GitHub Pages site hereO site ainda está publicando, ou o index.html não está na raiz.Espere; confira o nome e o lugar do index.html. Ver o passo
