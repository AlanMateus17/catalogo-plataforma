Como estudar por aqui

  1. Leia a explicação de um capítulo. Os capítulos estão em ordem: um prepara o próximo.
  2. Clique nas palavras coloridas dos exemplos. Cada uma abre a explicação dela. Sublinhado tracejado = nome criado por você.
  3. Mexa nos experimentos (caixas "Experimente"). Mude valores e veja o que acontece. Nada ali estraga.
  4. Faça os "Você tenta" no seu próprio projeto e responda os "Confira" antes de abrir a resposta.
  5. Feche o material e explique com as suas palavras o que acabou de aprender, em 3 a 5 frases. Se não conseguir, volte. É o que transforma "eu vi" em "eu sei".

Antes de começar: e a inteligência artificial?

Use IA como professor e revisor, nunca como quem faz o exercício por você. O guia Usar IA do jeito certo mostra onde ela ajuda, onde precisa de cuidado e onde ela tira o seu aprendizado.

Os módulos têm dois níveis. O nível aluno (módulos 1 a 6) vai da lógica ao front-end moderno. O nível profissional (7 a 17) continua até um sistema com back-end, banco de dados e deploy: é o caminho para a primeira vaga.

Comece por aqui: o que já dá para estudar hoje

  1. Leia o guia Usar IA do jeito certo (10 minutos).
  2. Siga o Passo a passo: do computador vazio ao seu site no ar.
  3. Junto com ele, estude o módulo 2: HTML, CSS e JavaScript. Cada passo de código da trilha indica o capítulo certo.

O próximo módulo publicado será o 1 (Lógica de programação). Os outros aparecem abaixo como "Em construção", para você já ver o caminho inteiro.

O mapa: como as peças de um sistema se conectam

Um sistema completo tem três partes que conversam entre si. Este é o destino: não precisa entender tudo agora. Os primeiros sites, como o do Passo a passo, só têm a parte 1 e ficam no GitHub Pages, que é gratuito. Quando o sistema ganha API e banco de dados, ele precisa de um servidor (módulo 15).

1. Front-end

O que roda no navegador da pessoa

  • HTML, CSS, JavaScript
  • TypeScript
  • React + Next.js
  • Tailwind
pedido HTTP →← resposta JSON

2. Back-end (API)

O que roda no servidor: regras e segurança

  • C# + .NET 10
  • ASP.NET Core
  • Clean Architecture + DDD
  • SignalR (tempo real)
consulta SQL →← dados

3. Dados

Onde as informações ficam guardadas

  • PostgreSQL (+ PostGIS)
  • Redis (cache e filas)

Por baixo de tudo: Git e GitHub (guardar e colaborar), testes automatizados, Docker (empacotar), GitHub Actions (testar e publicar sozinho), servidor com domínio e HTTPS (hospedar) e observabilidade (saber o que está acontecendo).

Roteiro para a primeira vaga fullstack

Os módulos são a teoria organizada por assunto. O roteiro é a ordem de estudo, em etapas: cada etapa junta alguns módulos e termina com algo funcionando. Não pule etapas: cada uma se apoia na anterior.

  1. Etapa 1 Lógica de programação

    Variável, decisão, repetição, função e coleção, resolvendo problemas antes de pensar em linguagem.

    Pronto quando: Resolve exercícios de lógica sem travar e explica a solução em voz alta.

    Módulo: 1

  2. Etapa 2 O primeiro site no ar

    HTML, CSS e JavaScript na prática, seguindo o Passo a passo até publicar no GitHub Pages.

    Pronto quando: O seu site está no ar e você explica cada linha dele.

    Módulos: 2, 3

  3. Etapa 3 Trabalhar como equipe e entender a web

    Git com branch e pull request, e o que acontece entre o navegador e o servidor (HTTP, DNS, CORS).

    Pronto quando: Abriu um pull request num projeto e explica o que é um pedido HTTP.

    Módulos: 3, 4

  4. Etapa 4 Front-end moderno

    TypeScript, React e Next.js, com Tailwind.

    Pronto quando: Refez o seu site (ou parte dele) em Next.js, com componentes.

    Módulos: 5, 6

  5. Etapa 5 C# e orientação a objetos

    A linguagem do back-end: classes, interfaces, coleções, LINQ, async/await.

    Pronto quando: Modela um problema real com classes e explica cada decisão.

    Módulos: 7, 8

  6. Etapa 6 Banco de dados

    Modelar tabelas, escrever SQL e usar o PostgreSQL.

    Pronto quando: Criou o banco de um sistema pequeno e escreve as consultas dele.

    Módulo: 10

  7. Etapa 7 API com ASP.NET Core

    Criar a API, ligar ao banco com EF Core e proteger com login.

    Pronto quando: Uma API com cadastro, listagem e login funcionando.

    Módulos: 9, 10, 12

  8. Etapa 8 Testes automatizados

    Testar o back-end e o front-end para mudar sem medo.

    Pronto quando: O fluxo principal do sistema tem testes que rodam sozinhos.

    Módulo: 14

  9. Etapa 9 Projeto de portfólio no ar

    Um sistema completo (front, API e banco) empacotado com Docker, publicado e com deploy automático.

    Pronto quando: Qualquer pessoa abre o seu sistema pela internet, e o README explica como ele funciona.

    Módulos: 15, 17

  10. Etapa 10 Preparar-se para as vagas

    Portfólio, GitHub organizado, algoritmos básicos e treino de entrevista.

    Pronto quando: Apresenta o seu projeto em 2 minutos e responde perguntas técnicas sobre ele.

    Módulos: Além do código

E depois da primeira vaga?

Alguns assuntos fazem mais sentido quando você já trabalha num sistema de verdade: Clean Architecture, DDD e multi-tenant, Redis e SignalR, Performance. Eles continuam na lista de módulos, marcados como "Depois da primeira vaga".

A stack desta documentação (C# com .NET, PostgreSQL e Next.js) é uma das usadas no mercado. Outras stacks, como Java ou Node.js no back-end, seguem as mesmas etapas: o que muda é a linguagem.
