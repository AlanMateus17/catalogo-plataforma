Verificador do projeto

Escolha a pasta do seu site. A página confere os caminhos, o HTML, o CSS e o JavaScript, e diz como corrigir cada problema.

Escolher a pasta

O navegador vai perguntar se você quer "enviar" os arquivos. Pode confirmar: os arquivos não saem do seu computador. A página só lê o conteúdo, aqui mesmo no navegador.

O que o Verificador não vê

  • Ele não abre o site: não testa cliques, animações nem a aparência. Para isso, use o Live Server e o F12 (Passo 8).
  • A conferência de tags é pela contagem de aberturas e fechamentos. O validador do W3C é mais completo e mostra a linha exata.
  • Um item de atenção nem sempre é erro. Leia a explicação e decida.
