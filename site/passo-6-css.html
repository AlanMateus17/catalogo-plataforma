6.1 As suas cores

O estilo.css da estrutura começa com as variáveis de cor. Troque pelos códigos das suas cores (um site como coolors.co ajuda a escolher):

Exemplo em css/estilo.css

:root {
  --cor-principal: #5a189a;  /* cabeçalho, botões, links */
  --cor-destaque: #ff9e00;   /* realces */
  --cor-fundo: #f7f4fb;
  --cor-texto: #1d1330;
}

Os códigos prontos usam cores fixas, como #12324a e #ffb703. Troque todas de uma vez pelas variáveis:

  1. Antes, confira que o :root já tem as suas cores. Se ele ainda tiver #12324a, a troca cria --cor-principal: var(--cor-principal); e todas as cores quebram.
  2. No estilo.css, aperte Ctrl + H (Localizar e substituir).
  3. Em cima, #12324a; embaixo, var(--cor-principal). Clique em Substituir tudo.
  4. Repita com #ffb703 → var(--cor-destaque).

Confira: qual é a vantagem de escrever var(--cor-principal) em vez de #5a189a em cada regra?

Ver a resposta

Se um dia você quiser outra cor, troca uma linha só, no :root, e todas as regras mudam juntas.

6.2 A sua fonte

Escolha uma fonte em fonts.google.com (clique na fonte, depois em Get font e Get embed code). São duas partes:

No index.html, dentro do <head>, antes do link do estilo.css

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap">

No css/estilo.css

body {
  font-family: "Poppins", Arial, sans-serif;
}

Troque Poppins pelo nome da fonte que você escolheu, nas duas partes. O Arial, sans-serif depois dela é a reserva, se a fonte não carregar.

6.3 Ajustar para o celular

Primeiro, veja como está:

  1. No navegador, aperte F12 e depois Ctrl + Shift + M.
  2. No topo, escolha uma largura de celular, como 390.
  3. Role a página toda. Rolagem para o lado ou algo cortado mostra onde precisa de ajuste.

Depois, corrija com @media: as regras de dentro só valem em telas até aquela largura. Coloque no final do estilo.css:

No final do css/estilo.css (troque .grade e .cards pelas classes do seu site)

@media (max-width: 700px) {
  /* colunas lado a lado viram uma coluna só */
  .grade, .cards {
    grid-template-columns: 1fr;
  }
  /* título menor no celular */
  h1 {
    font-size: 2rem;
  }
}

As imagens a estrutura já resolve: a regra img { max-width: 100%; } dela impede que uma foto fique maior que a tela.

Erro comum: mudei o CSS e nada aconteceu.

Clique com o botão direito no elemento e escolha Inspecionar. À direita aparecem todas as regras que valem para ele. Uma regra riscada está perdendo para outra mais forte ou que vem depois no arquivo. Por isso o @media vai no final.

Erro comum: a imagem de fundo do CSS não aparece.

Dentro do CSS, o caminho parte da pasta css. O certo é url("../img/foto.jpg"): o ../ volta uma pasta antes de entrar em img.

E a IA, neste passo?

Pode: pedir para explicar por que uma regra não funciona, ou para revisar o seu CSS e apontar repetições.

Não: pedir o CSS do site inteiro pronto. Você não vai saber mudar depois.

Por quê, e prompts prontos para usar do jeito certo: Usar IA do jeito certo.

Você tenta

Escreva três regras suas, que não vieram prontas: um :hover diferente nos links, uma borda nos títulos h2 e uma cor de fundo alternada nas seções (section:nth-child(even)).

6.4 Guardar no GitHub

Terminou este passo? Registre a versão e envie. Assim, se o computador do laboratório for formatado, o seu trabalho estará salvo no GitHub.

Git Bash
$ git status$ git add .$ git commit -m "Aplica cores, fonte e ajuste para celular"$ git push

Troque a mensagem se quiser: ela deve dizer o que mudou. O site ainda não está no ar; publicar é o Passo 9.

Outro computador, ou começou a aula agora? Antes de editar, traga o que já está no GitHub: veja o Passo 10.3.
