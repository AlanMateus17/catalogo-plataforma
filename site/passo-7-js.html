7.1 A primeira interação

Comece pela mais simples. Cole as três abas deste painel: o HTML onde quiser o botão, o CSS no final do estilo.css e o JS no final do script.js.

Clique no botão. Funcionou? Então o caminho está certo: HTML, CSS e JS se encontrando.

Confira: o JavaScript do botão Curtir não muda nenhuma cor. Quem faz o botão ficar vermelho?

Ver a resposta

O CSS. O JavaScript só coloca a classe curtido no botão; a regra .btn-curtir.curtido do CSS diz que ele fica vermelho.

E a IA, neste passo?

Pode: colar a mensagem de erro do Console e pedir para explicar o que ela quer dizer, depois de você ter lido a mensagem e a linha.

Não: pedir o código de uma interação inteira. Adaptar um código pronto que você entende ensina; colar um que você não entende, não.

7.3 Ler um erro do Console

Com o site aberto, aperte F12 e abra a aba Console. Um erro em vermelho parece assim:

Exemplo de erro

Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
    at script.js:14:13
  • O que aconteceu: Cannot read properties of null quer dizer que o JavaScript procurou um elemento e não o encontrou (recebeu null).
  • Onde: script.js:14:13 é o arquivo, a linha 14 e a coluna 13. Clique nesse texto: o navegador mostra a linha.
  • Por quê, quase sempre: o id do getElementById não é igual ao id do HTML, ou o <script> está sem defer.

Quando nada acontece e não há erro, descubra o que o código está vendo com console.log. No seu script.js, logo abaixo da linha const btnCurtir = document.getElementById("btn-curtir"); que já existe, acrescente só esta linha:

Uma linha a mais em js/script.js

console.log("achei o botão?", btnCurtir);   // null = não achou

Erro comum: colar a linha const btnCurtir = ... de novo.

Dá SyntaxError: Identifier 'btnCurtir' has already been declared e o arquivo inteiro para de funcionar. Um nome criado com const só pode ser criado uma vez.

Erro comum: colar só uma ou duas das abas.

Sem o CSS, o elemento aparece sem forma. Sem o JS, ele aparece, mas não faz nada. Confira se as três abas do painel foram coladas, cada uma no seu arquivo.

Erro comum: Uncaught SyntaxError: Unexpected end of input.

Falta fechar uma } ou um ), quase sempre no fim do último código colado. Compare o final do seu script.js com o final da aba JavaScript do painel.

Você tenta

Mude o id do botão Curtir no HTML para btn-curtir2, salve e veja o que acontece (e o que não aparece no Console). Use o console.log para descobrir o motivo. Depois desfaça.

7.4 Guardar no GitHub

Terminou este passo? Registre a versão e envie. Assim, se o computador do laboratório for formatado, o seu trabalho estará salvo no GitHub.

Git Bash
$ git status$ git add .$ git commit -m "Adiciona interações com JavaScript"$ git push

Troque a mensagem se quiser: ela deve dizer o que mudou. O site ainda não está no ar; publicar é o Passo 9.

Outro computador, ou começou a aula agora? Antes de editar, traga o que já está no GitHub: veja o Passo 10.3.
