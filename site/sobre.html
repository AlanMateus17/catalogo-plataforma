Por que esta segunda página existe?

Para você ver, na prática, três coisas:

  1. Links entre páginas funcionam com o nome do arquivo: href="sobre.html".
  2. O mesmo CSS deixa as duas páginas com a mesma cara, sem copiar nenhuma regra.
  3. O mesmo JavaScript funciona nas duas, mesmo que esta página não tenha a maioria dos exemplos. Veja no script.js como cada parte confere se o elemento existe antes de usar.
Teste: ligue o tema escuro aqui e volte para a página inicial. O tema continua escuro, porque o JavaScript guardou a escolha no localStorage do navegador, que é o mesmo para as duas páginas.
