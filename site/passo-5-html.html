Montar o conteúdo com HTML

Para entender a fundo

Este passo usa o que está explicado na Documentação. Leia antes, ou volte lá quando uma palavra não fizer sentido:

  • Anatomia de um elemento: tag, atributo, aninhamento
  • Semântica: qual tag usar para cada coisa
  • Links, imagens e o atributo alt

5.1 Planejar antes de digitar

  1. Escolha o tema e divida o assunto em 4 a 6 seções. Exemplo: Início, História, Lugares (galeria), Como chegar (mapa), Contato.
  2. Desenhe a página numa folha, de cima para baixo: cabeçalho com menu, primeira área grande, uma caixa para cada seção e o rodapé.
  3. Ao lado de cada caixa, escreva o código pronto que vai usar. A lista está na página Códigos.

Sobre o formulário de contato: no seu site ele funciona na tela, mas não envia e-mail sozinho, porque um site no GitHub Pages não tem servidor. A nota do código Formulário mostra como usar um serviço gratuito que recebe as mensagens.

Confira: por que a sua página deve ter um único <h1>?

Ver a resposta

O h1 é o título da página inteira. O Google e os leitores de tela o usam para saber do que a página trata. As seções usam h2.

5.2 Trocar as partes da estrutura pelos blocos completos

A estrutura do Passo 3 tem um cabeçalho, uma primeira seção e um rodapé simples. Os blocos abaixo são as versões completas. Cada um substitui uma parte da estrutura: não cole os dois, senão a página fica com dois cabeçalhos e dois h1.

BlocoNo index.html, apague......e cole no mesmo lugar
Cabeçalho com menuo <header class="topo"> inteiro, até o </header>a aba HTML do cabeçalho
Herói (primeira área grande)a <section id="inicio"> inteira, até o </section>a aba HTML do herói
Rodapéo <footer class="rodape-simples"> inteiroa aba HTML do rodapé

As abas CSS e JavaScript vão para o final do estilo.css e do script.js. No menu do cabeçalho, deixe só os links das seções que o seu site tem: um link #galeria sem uma seção id="galeria" não leva a lugar nenhum.

Erro comum: dois cabeçalhos, dois rodapés ou dois h1 na página.

Você colou o bloco completo sem apagar a parte simples da estrutura. Apague a versão simples (veja a tabela acima). O Verificador acusa isso como id repetido (inicio).

5.3 Montar as outras seções, um bloco de cada vez

Para cada caixa do seu desenho:

  1. Abra o painel Ver código do bloco na página Códigos.
  2. Leia o Entenda este código: cada palavra colorida tem explicação. Não cole o que você não entendeu.
  3. Copie a aba HTML e cole no index.html, dentro do <main>, no ponto onde essa seção fica no seu desenho.
  4. Copie as abas CSS e JavaScript, se existirem, para o final do estilo.css e do script.js.
  5. Troque textos, fotos (src e alt) e links pelos seus.
  6. Salve e confira no navegador antes de passar para o próximo bloco.

E a IA, neste passo?

Pode: pedir para explicar uma tag ou um erro, ou para revisar o seu HTML pronto e apontar problemas de semântica e acessibilidade.

Não: pedir para a IA gerar a página ou uma seção inteira. Montar e entender cada bloco é o que este passo ensina.

Por quê, e prompts prontos para usar do jeito certo: Usar IA do jeito certo.

Erro comum: o link do menu não leva para a seção.

O href="#lugares" precisa ser exatamente igual ao id="lugares" da seção: mesmas letras, sem acento, sem maiúscula.

Erro comum: a página fica torta do meio para baixo.

Uma tag abriu e não fechou, ou você copiou um </div> a mais. No VS Code, clique numa tag de abertura: ele destaca a de fechamento. A setinha ao lado do número da linha recolhe o bloco e mostra onde ele termina.

Você tenta

Escolha na página Códigos um bloco que ainda não está no seu site (galeria, cards ou tabela), cole e adapte ao seu tema.

5.4 Conferir o HTML

Abra o Verificador do projeto, escolha a pasta do seu site e corrija os itens em vermelho: ele encontra id repetido, imagem sem alt, caminho errado e tag sem fechar. A conferência completa, com o validador oficial, fica para o Passo 8.

5.5 Guardar no GitHub

Terminou este passo? Registre a versão e envie. Assim, se o computador do laboratório for formatado, o seu trabalho estará salvo no GitHub.

Git Bash
$ git status$ git add .$ git commit -m "Adiciona o conteúdo do site"$ git push

Troque a mensagem se quiser: ela deve dizer o que mudou. O site ainda não está no ar; publicar é o Passo 9.

Outro computador, ou começou a aula agora? Antes de editar, traga o que já está no GitHub: veja o Passo 10.3.

Pronto quando
